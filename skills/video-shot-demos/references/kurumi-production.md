# 久留美定制视频：字幕、进度与同步

## 本 fork 默认层次

1920×1080 舞台，主要图解在上方；放大角色与侧向气泡在两侧；字幕及当前话题进度在下方。角色、字幕、进度属于 `#cam` 外的独立层。

可使用内置层：

```js
const film = FXKurumi.timeline({
  stage: '#stage',
  title: '当前主题',
  start: 0,
  total: 30,
  topics: [{start:0,title:'认识 GEX'}, {start:15,title:'动态对冲'}],
  captions: [{start:0,end:4,text:'本期讨论期权市场的对冲机制。'}]
});
// 模板 tick 已调用 FXKurumi.tick(el)。自建页面也应把同一虚拟时钟传入：
// FXKurumi.tick(elapsedMilliseconds)
```

## 字幕

默认为简体中文、书面语。保留句意、术语及数据，整理口语填充词，避免把识别错误照抄成字幕。优先使用原声时间戳；字幕与口播按句/短句对齐，而不是等一整段讲完再显示。

主题配色默认纸色底板、墨绿正文、强调红标注术语和数值。字幕直接显示在视频画面中；需要时另给 SRT/VTT。每条长度以一行可读为宜；不能通过无限缩小字号塞长句，必要时按语义拆分。

默认字幕区域约 y=944–1007。角色脸部、气泡与图解结论留在其上方；双人页面尤其检查右侧气泡与字幕交叠。可调整这个示例布局，以用户确认的样板为准。

## 主题进度

常驻当前主题、已播时间、总时长及主题色条。底板应覆盖角色下半身，确保深色衣服上也可读；它不是仅鼠标悬停才出现的原 HUD。Q 版行走角色不在此包内，默认普通标记即可。

跨镜头用全局时间：`start` 是本镜头在整片的起点，`total` 是整片时长，不能每个镜头从零重置整条影片的进度。

## 音频与裁切

使用用户已有音频时保留原声，不自动重写或合成替代配音。用户要求去掉 intro 音乐时，先确认正文的实际开始时刻，再对音轨、字幕、章节和时间轴统一应用同一个偏移。浏览器启动按钮的 2 秒淡出不算原声音频时长。

## 交付检查

检查具体变动可能造成的失败：图像加载、四格取用、脸部和气泡遮挡、字幕溢出、时间偏移和播放。共用布局可抽样检查，已经通过且未改动的证据可复用。普通素材复制、保存和 Git 提交不额外添加 SHA256/MD5 验证。可观看结果生成后及时告知用户。
